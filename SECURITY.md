# Security

Twinwave measures audio locally and does not use the network. The App Store target is sandboxed with audio-input access only. See [the privacy policy](docs/PRIVACY.md) and [the publication review](docs/SECURITY_REVIEW.md).

For a suspected vulnerability, use GitHub’s **Security → Report a vulnerability** option when available. Do not publish exploit details, recordings, credentials, or personal device data in a public issue. Ordinary non-sensitive bugs can be filed in Issues.

Security review reduces risk; it does not prove the absence of vulnerabilities. Review changes to capture code, permissions, dependencies, build scripts, or data handling before release.
